# 確かめること（S26 で）

まだスマホ（S26）で確かめていないものの一覧。ゲームの中では、URL に `?dev` を付けて開き、左下の「開発」→「確かめること」でも見られる（同じ中身）。
ゲームの中では、「行く」で確かめる場所へ飛べ、「できた／おかしい」を押すと開発用の保存に残る。

全部で 43 項目。

## 表と裏の戦い

### 1. 表と裏を行き来できる。見ていない方は自動で動く

**やり方**

1. 「行く」で材料の戦いを始める
2. 右上の水色の「⇄ 裏へ」を押す
3. 裏の画面の右上の「⇄ 表へ」を押す

**こうなれば正しい**：画面が切りかわる。裏を見ている間も、右の欄の表の4人のHPが動き、戦いが自動で進む。表にもどると、自分で技を選べる

「行く」：材料の戦い

### 2. 裏で、点を押して侵入できる

**やり方**

1. 戦いの中で「⇄ 裏へ」
2. 光っている点（入口のとなりの「中継」など）を押す

**こうなれば正しい**：緑の点線がのびて、数秒で点に色がつく。左下に「〜を破った」と出る。次に押せる点が光る

「行く」：材料の戦い

### 3. 検知の光と追跡ゲージ

**やり方**

1. 裏で、赤い光が通っている線の先の点を押して、そのまま待つ

**こうなれば正しい**：上の「追跡」のゲージがたまり、満タンで「回線を切られた…しめ出し中」が出て、4秒ほど何もできず入口にもどる。開発の「裏の追跡ゲージを止める」をオンにすると、たまらない

「行く」：材料の戦い

### 4. 弱点は「？」で始まり、裏で暴くと見える

**やり方**

1. 表で、敵の頭の上の札が「？？」なのを見る

**こうなれば正しい**：札の「？」が属性の色（炎・風など）に変わる。敵に〔析〕がつく。16秒ほどで点は直されるが、弱点は見えたまま

「行く」：材料の戦い

### 5. ボスの防壁は、裏で防壁の点を破っている間だけ消える

**こうなれば正しい**：[防壁] が消え、与えるダメージがはっきり大きくなる。しばらくすると点が直され、[防壁] がもどる

「行く」：ボス戦

### 6. 盗む。盗んだ物を味方に渡せる

**やり方**

1. アカリの通常攻撃（ときどき盗む）か、裏で「強化」の点を破る

**こうなれば正しい**：盗んだ物が減り、番の人に〔盗〕（攻撃力アップ）がつく。ボスの「力をためる」を盗むと大技が止まる

「行く」：材料の戦い

## 戦いの画面（固まる・自動のボタン・押しやすさ）

### 38. 戦いの途中で固まらない（群れが入れかわるところ）

**やり方**

1. 「行く」で群れが2つある戦いを始める
2. 右上の「自動」を ON、「速さ」を ×3 にする
3. 「⇄ 裏へ」と「⇄ 表へ」を何度か行き来し、合わせ技が光ったら押す（自動を OFF にしたとき）
4. 1つめの群れを倒して、2つめの群れが出るところを何回か見る

**こうなれば正しい**：最後まで止まらずに戦いが終わり、結果の画面が出る。「問題が起きました（記録しました）」が出たら、開発の「道具」の「不具合の記録」を見る

「行く」：資料室の警備 I（群れ2つ）

### 39. もし固まったら、手がかりが残る

**やり方**

1. （ふつうに遊んでいて固まったときも）URL の最後に ?dev を付けて開き直す
2. 左下の「開発」→「道具」の、いちばん上の「不具合の記録」を見る

**こうなれば正しい**：いつ・どこで（frame／battle／stall など）・何が起きたかと、そのときの戦いのようす（番・群れ・自動・速さ・裏）が出る。中身を写真で送ってもらえば原因を探せる。「記録を消す」で消える

「行く」：夜の拠点

### 40. 自動と速さのボタンが、ON か OFF か一目で分かる

**やり方**

1. 戦いの中で、右上の「自動」と「速さ」を何回か押す

**こうなれば正しい**：OFF はうすい点線のふちで、下に「OFF」「×1」。ON は自動が緑・速さが金色にぬりつぶされて光り、右上の小さな灯りが点滅する。下に「ON」「×2」「×3」

「行く」：材料の戦い

### 41. 自動のあいだは下に「自動で戦闘中」の帯。押すと手動にもどる

**やり方**

1. 戦いの中で「自動」を ON にする

**こうなれば正しい**：ON のあいだは帯が出て、合わせ技の列は出ない（自動で撃つため）。帯を押すと自動が OFF になり、自分の番でコマンドが出る。結果の画面や拠点では帯は出ない

「行く」：材料の戦い
