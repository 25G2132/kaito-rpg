# 怪盗RPG 作る計画

2026-11-18。もとの設計書：[2026-11-18-design.md](2026-11-18-design.md)

進め方：段階ごとに「できたかどうか」を確かめてから次へ進む。どの段階でも、ブラウザで動かして確かめる。戦いの計算のようにロジックだけの部分は、自動テストで確かめる。

## 段階 0：準備（半日）　※2026-11-18 完了

- `kaito-rpg` で git を始める。Vite ＋ TypeScript ＋ Three.js ＋ three-vrm を入れる。版は始めた日の安定版に固定する。
- 横画面で開く。縦のときは「横にしてください」と出す。
- 画面の左上に、重さの表示（1秒あたりのコマ数、描く回数、使っているメモリ）を出す。開発中だけ出す。
- **スマホで開く方法**：
  - 家のWi-Fiでは、パソコンの開発サーバーをスマホから開く。
  - 外では、GitHub Pages に上げて開く。
- GitHub に置き場所（リポジトリ）を作り、GitHub Pages で公開する。**作る前にユーザーに確かめる**（名前、公開か非公開か）。

できた印：Galaxy S26 で横画面の空の3D画面が開き、重さの表示が出る。

## 段階 1：重さの試作（1〜2日）　※2026-11-18 完了

- VRoid のキャラを4体、敵の仮の形を3体並べる。キャラは待機の動きで揺らす。戦いの画面と同じカメラ・光・影にする。
- 3つの条件で重さを測る。
  - キャラの面の数と絵の大きさ：VRoid の書き出しで減らす前と後
  - 影のあり・なし
  - 画面の細かさ（解像度）
- 確かめる実機は Galaxy S26 だけ（iPhone は持っていない）。iPhone の人のために、メモリは控えめの目安を置く。
- 結果を `docs/perf-budget.md` に書く。中身は、キャラ1体の面の数・絵の大きさの上限と、戦いで同時に映す人数。

できた印：Galaxy S26 で、4体＋敵が滑らかに動き、10分で落ちない設定が見つかる。

**結果（2026-11-18 完了）**：Galaxy S26 はどの条件でも 60fps、10分で落ちず熱くもならない。目安は [perf-budget.md](perf-budget.md)。見つからなければ止まり、対策をユーザーと決める（映す人数を減らす、など）。

## 段階 2：戦いの芯（4〜6日）　※2026-11-18 完了

- 戦いの計算は、画面と切り離して作る。`src/battle/`。自動テストつき。
  - 行動の順番（素早さ）、通常攻撃・スキル・必殺技
  - 全員で共有する点数、必殺技のゲージと割り込み
  - 弱点の属性と守りが崩れる仕組み、相性の効果
  - 敵の動き、勝ち負け
- キャラの数字と技は、データとして書く（`src/data/`）。キャラを足すときにコードを変えずに済むようにする。
- 画面：順番の表、技のボタン、必殺技の割り込み、ダメージの数字、相性がかみ合ったときの演出、倍速、自動戦闘。
- 動きは無料の VRMA 素材とプログラムで作る。足りなければ Mixamo を使う（ユーザーのアカウントが要る）。

できた印：仮のキャラ4人で敵の群れとボスに勝てる。相性のいい組み合わせのときに、数字と演出がはっきり大きくなる。

**結果（2026-11-18）**：計算は `src/battle/`（自動テスト21本）、データは `src/data/`。属性は炎・氷・雷・風・影の5つ。仮の4人＝アカリ（炎・アタッカー）、シン（雷・ハッカー支援）、ユキ（氷・守り/回復）、ハヤテ（風・範囲）。相性は「シンの〔解析〕→ 紅蓮一閃が2倍」「アカリの〔燃焼〕→ 煽り風が2倍にして燃やす」。ボス「番人クロガネ」は力をためて大技（崩すと止まる）、HP半分で怒る。自動で戦わせると、レベル20で群れ→ボスにほぼ必ず勝ち、レベル10ではほぼ負け（段階3の釣り合いの出発点）。動きはプログラムで作った（VRMA・Mixamo はまだ使っていない）。Galaxy S26 で遊んで、問題なく動くことを確かめた。

## 段階 3：育成と装備 → 先行版（3〜5日）　※2026-11-20 完了（ユーザーが遊んで「このまま進めよう」）

- レベル（章ごとの上限、材料で上限を上げる）、技レベル、専用武器、装備4枠（副ステータスはランダム、強化で伸びる）。
- 保存はブラウザの中にする。読んだ形を確かめ、おかしければ初期値に戻す。
- 育成の画面を作る。何を上げると何が強くなるかが、数字で見えるようにする。
- 戦いの繰り返し：材料が出る戦いをくり返せるようにする。
- 釣り合い：「育てずにボスへ行くとまず負け、育てると勝てる」を自動テストで確かめる。戦いを機械に何百回も回させて、勝率を出す。

できた印 ＝ **先行版**：戦う → 育てる → 前に負けたボスに勝てる、が通しで遊べる。GitHub Pages に上げて、ユーザーが遊ぶ。**ここで手ごたえを確かめてから、先へ進む。**

**結果（2026-11-18）**：育成は `src/progress/`、画面は `src/ui/`。はじめはレベル5（上限10）。レベルは参考書と勝ったときの経験値で上がり、鍵の欠片で「突破」すると上限20（第1章の上限）。技レベルは技の手帳で4まで（1つで技の倍率+10%）。専用武器は設計図の切れ端4つで作る。装備は仮面・手袋・靴・記章の4枠で、副ステータスはランダム、部品で+15まで強化（3レベルごとに副ステータスが増える／伸びる）。材料の戦いは「夜の見回り」（参考書・部品・装備）と「資料室の警備」（技の手帳・鍵の欠片・設計図）で、それぞれ段階 I〜III がある（前の段階に勝つと次に挑める。上ほど敵が強く、出る物が多く、★の高い装備が出る）。装備は★2〜★5（★が高いほど主な効果が強く、副ステータスが多く、強化の上限が高い）。

**ユーザーの声で直した（2026-11-18）**：一瞬で周回できると材料が集まりすぎて育成の面白さがなくなり、勝つ喜びも少ない → 「すぐ終わらせる」をなくし（自分で戦う。自動・倍速は使える）、1回にもらえる量を減らし、段階と★を入れ、ごほうびを1つずつ光らせて見せるようにした。ボス「金庫室の番人」は、育てずに挑むと勝率5%以下、材料の戦い10回ではまだ勝てず、25回ほど育てるとほぼ勝てる（自動テストで何百回も戦わせて確かめる）。どの育成ボタンにも「押すと何がどれだけ上がるか」と戦力の増え方を出す。

**宿題（あとでユーザーと決める）**：戦いのスキップ（一瞬で周回する仕組み）。育成の面白さを壊さない形を考える（例：参考書だけ、回数に上限、など）。

## 段階 4：歩く場所と怪盗の仕掛け（5〜7日）　※2026-11-20 完了（ユーザー「いい感じ」）

- 忍び込む建物を1つ作る。左のスティックで歩き、右手で調べる・走る・カメラを回す。
- 敵が見えていて、触れると戦いになる。先に叩けば有利な状態で始まる。
- 宝箱と材料。
- 影の中を通って監視カメラ・見回りをかわす仕掛けと、ハッキングで扉やカメラを止める仕掛け。
- 建物の奥でボスと戦う。

できた印：建物に入り、見つからずに進み、ボスを倒して出られる（10〜20分）。

**結果（2026-11-20）**：計算は `src/field/`（自動テストつき）、地図は `src/data/maps.ts`、画面は `src/fieldView/`。建物は「黒金邸」（名前は仮）：庭 → 玄関ホール → 資料室 → 金庫室の前 → 番人（ボス）。形はすべてプログラムで作った。左半分をなぞるとスティック、右半分でカメラ、右下に攻撃・調べる・走る、右上に小さな地図。パソコンは WASD・Shift・Space・E。見回りは決まった道を歩き、見える範囲が床に扇で出る（見られ続けると見つかり、追ってくる）。監視カメラに見つかると、近くの見回りが来る。影の中にいると見つからない。端末は影の中にあり、隠れたままシンがハッキングしてカメラを止め、扉を開ける（途中で見つかると止まる）。気づかれていない見回りに攻撃を当てると先制（敵の番が遅れ、守りが削れる）、見つかってぶつかられると不意打ち（敵が先に動く）。宝箱4つ。ボスの扉に一度着くと、拠点からもボスに挑める。見回りに負けると「捕まってしまった…」で拠点へ、ボスに勝つと「脱出成功！」。

**宿題（これから詰める）**：ロボットなど見回りの動き（今は決まった道を通り、本棚などを通り抜けることがある）。物と重なったときの判定（体の当たり方、敵とぶつかる近さ）。

## 段階 5：学校の拠点と絆（4〜6日）

- 学校と街を歩ける場所にする。
- 仲間と話すと絆が上がり、段階ごとに相性の効果や技が開く。
- 昼（学校）と夜（怪盗パート）の切り替え。
- 行事のミニゲームを1つ作る（何にするかは段階 7 の物語と合わせて決める）。

作り方（2026-11-20）：昼は学校を歩き、仲間（シン・ユキ・ハヤテ）に話しかけると絆が上がる（1日3回まで）。絆は Lv1〜5。上がるごとに数字・相性の効果・技の新しい効果が開く（データで書く）。夜は今の拠点（忍び込む・材料の戦い・育てる）。夜に「寝る」と次の日の昼。会話の文は仮（段階7で直す）。ミニゲームは計画どおり段階7で物語と合わせて決める。街は物語の場所が決まってから作る。
