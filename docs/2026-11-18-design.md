# 新しいRPG 設計書

2026-11-18 ユーザー承認済み。題名は未定（仮に「怪盗RPG」と呼ぶ）。
「影の道」とは別のゲーム。「影の道」（kage-no-michi / kage-no-michi-story）は何も変えない。

印の意味：**［決定］** ユーザーが選んだ／言ったこと。**［案］** こちらの提案（ユーザーはまだ否定していない）。**［任せる］** 作り手が決めてよいこと。

---

## 1. なぜ作るか

- ユーザーが味わいたいのは「**強くなっていく手ごたえ**」。［決定］
- 手本は「崩壊：スターレイル」と「原神」。気持ちいい瞬間として挙がったのは、キャラを少しずつ育てる、敵を倒すタイミング、ガチャで欲しいキャラが当たる、ストーリーが良い、好きなキャラの強化、キャラ同士の相性が最高の瞬間、欲しい装備のステータスが出る、強敵を倒す、新マップ解放、専用武器が手に入る、新キャラ発表、キャラ・装備・ストーリーの作り込み。［決定］
- つまり中心は「**キャラを集めて、育てて、組み合わせて、強敵に勝つ**」。そこに作り込んだ物語と、新しい場所が開く楽しさがのる。

## 2. 目標・目標外・失敗の形

**目標**
- 育てた分だけ戦いが楽になり、前に勝てなかったボスに勝てる。
- 相性のいい組み合わせが、目に見える大きな数字・演出で分かる。
- ガチャで欲しいキャラが当たった瞬間が、1枚絵と演出で気持ちいい。
- 昼の学校のわくわくと、夜の怪盗の緊張が交互に来る。

**目標外（今回は作らない）**［案：ユーザー未否定］
- お金を取る仕組み（課金ガチャ、有料パス）。ガチャは遊んで貯めた石だけで引く。
- スタミナ制限。
- 広い地図（オープンワールド）。
- オンラインの対戦・協力。
- 日付に追われるカレンダー（何日までに○○、の仕組み）。
- 有名作の再現。ジャンルや仕組みが近いのはよいが、名前・キャラ・見た目・物語は自前。「学校＋怪盗」はペルソナ5と近いので、細部を寄せない。

**失敗の形**（動いても失敗）
- 育てても戦いが変わらない（手ごたえがない）。
- スマホで重くてカクつく、熱くなる。
- ガチャが渋すぎて欲しいキャラが来ない（天井がない）。
- 学校パートが作業になり、怪盗パートへの寄り道でしかない。

## 3. 前提・制約

- **スマホ横画面**で遊ぶ。［決定］
- YouTube ゲームルーム（Playables）は「出せたら出す」。［決定］
  - 注意：ゲームルームは容量の決まりが厳しい（「影の道」は 512KiB を目安にしていた）。VRoid の3Dキャラは1体で数MBあるので、そのままでは入らない見込み。**本命の公開先はふつうのWebページ（GitHub Pages）**にする。［案］
  - ゲームルーム用の別の軽い版は**作らない**。決まりが変わるなどして出せる形になったら出す。［案・作り手の判断］
- 使うものに制限なし：外の素材、GitHub、ほかのAIへの指示文、「影の道」以外のものも可。［決定］
- 「影の道」の決まり（3色、書体2種、ファイルを読み込まない）は引き継がない。
- 作る人：コードは Claude。ユーザーの手作業は「VRoid でキャラを作る」「ほかのAIで1枚絵を描かせる（指示文は Claude が書く）」。

## 4. 作り方の比較（Approaches）

| 案 | 中身 | 良い点 | 弱い点 |
|---|---|---|---|
| **1：ブラウザ（Three.js）** ← **選んだ**［決定］ | Three.js（新しい版）＋ VRoid のキャラを読む道具（three-vrm） | Claude がコードを全部書いてブラウザで確かめられる。ゲームルームへの道が残る。「影の道」で慣れた作り方 | スマホで3Dキャラを何体も動かすと重い。軽くする工夫がずっと要る |
| 2：Unity | ゲーム作りのソフト | スマホで軽い。アプリとしてストアに出せる | 画面を見ながらの手作業が多く Claude にできない。ユーザーの作業が大きく増える。ゲームルームは難しい |
| （捨てた）1つのHTML | 「影の道」と同じ形 | 小さい | 3Dキャラ・ガチャ・物語の量に足りない |

選んだ理由：ユーザーの手作業がいちばん少なく、ゲームルームの道も残るから。

## 5. 遊びの中身

### 5.1 一日の流れ ［決定：学校を拠点に］
- **昼：学校**（歩ける拠点）。仲間と話して仲を深める。仲が深まるとそのキャラが強くなる（相性の効果や新しい技が開く）。
- **夜：怪盗パート**（小さな場所を歩く）。忍び込んで、戦って、ボスへ。
- **章の区切り：行事**（文化祭・運動会・テストなど）を小さな遊び（ミニゲーム）として入れる。
- 1回の怪盗パートは **10〜20分**。学校は好きなだけいられる。［案］

### 5.2 マップ ［決定：小さな場所を歩く］
- 町・学校・忍び込む建物などの、区切られた小さな3Dの場所。広い地図は作らない。
- 操作：左手で歩く（画面の左に出るスティック）、右手で調べる・走る・カメラを回す。［案］
- 敵は場所の中に見えている。触れると戦い。先に叩けば有利な状態で始まる。［案］
- **怪盗の仕掛け**：監視カメラや見回りを、**影の中を通ってかわす**（「影の道」の仕掛けを生かす）。男の主人公のハッキングで扉やカメラを止めて道をつくる。［案］
- 宝箱、育成の材料が集まる場所を置く。
- 章が進むと新しい場所が開く（「新マップ解放」）。

### 5.3 戦い ［決定：順番に戦う］［細部は案］
- 4人で組む。素早いキャラから順に番が来る（順番の表が画面に出る）。
- 技：通常攻撃／スキル／必殺技。必殺技はゲージがたまれば**自分の番を待たずに割り込んで撃てる**（「倒すタイミング」の気持ちよさ）。
- スキルは全員で共有する点数を使う。通常攻撃で点数がたまる。［案］
- 敵には**弱点の属性**。弱点をつくと守りが崩れ、少しのあいだ動けなくなる。
- **相性**：「Aがかけた状態をBが倍にする」のような組み合わせ。かみ合うと大きな数字と演出が出る。
- 戦いの速さ：倍速と自動戦闘を用意する。［案］
- 属性の数や名前は［任せる］。ただし主人公2人とガチャ組で、組み合わせの相性が成り立つように散らす。

### 5.4 強くなる仕組み ［案］
| 仕組み | 中身 | 手ごたえ |
|---|---|---|
| レベル | 戦いや本（材料）で上がる。章ごとに上限があり、材料で上限を上げる | 少しずつ育てる |
| 技レベル | 材料で技を強くする | 好きなキャラを強くする |
| 武器 | 各キャラに**専用の武器**がある。ほかの武器も付けられる | 専用武器が手に入る |
| 装備 | 1人4枠。主な効果は決まっていて、**副ステータスはランダム**。強化すると副ステータスが伸びる | 欲しいステータスが出る |
| 絆（学校） | 学校で話すと上がる。段階ごとに相性の効果や技が開く | 日常と強さがつながる |

数字の釣り合い（何回でボスに勝てるか）は［任せる］。ただし「第1章のボスは、何も育てずに挑むとまず勝てず、育てると勝てる」くらいにする。

### 5.5 ガチャ ［案］
- お金は使わない。物語・宝箱・初めての達成でもらえる石で引く。
- **キャラガチャ**と**武器ガチャ**の2つ。確率は画面に出す。
- **天井**あり（決まった回数で必ず最上位が出る）。欲しいキャラが必ず手に入る道を残す。回数は［任せる］。
- 当たった時：最上位はキャラの1枚絵＋演出。
- 新キャラは、あとから「新キャラ発表」の形で足していく。

### 5.6 探す・集める・頼みごと ［決定：2026-11-20 ユーザーの案］
3Dの「妖怪ウォッチ」の遊びの**仕組みだけ**を取り入れる。名前・キャラ・見た目・物語はまねせず、このゲームのもの（怪盗・学校・夜の街）にする。
- **学校のにぎやかさ**：いろんな生徒や先生がいて、話しかけるとひとこと（うわさ・ヒント）。朝・昼休み・放課後で、いる人や場所が変わり、チャイムが鳴る。屋上・図書室・体育館・購買など、歩ける場所を増やす。明るい色と小物（黒板・ロッカー・掲示物）。
- **文字と切り替え**：会話の文字は1文字ずつ出る。場面が変わるときはロード画面（ひとことやヒント）を出す。
- **戦い**（順番に戦う形はそのまま）：必殺技の前に小さなタッチ遊び（なぞる・連打）で、うまくいくと強くなる。6人まで連れて行き、戦いの最中に前の4人と入れかえられる。弱らせた敵に「説得」すると仲間になりやすい。
- **敵が仲間になる・怪盗手帳（図鑑）**：戦ったあと、たまに敵が「協力者」になる。協力者は戦いに連れて行ける。出会った敵・協力者は怪盗手帳に残る。
- **解析レンズで探す**：シンの解析レンズをかざすと、学校や街や屋敷に隠れたもの（物陰の材料、隠れた敵、うわさの手がかり）が見える。隠し要素を散りばめる。
- **頼みごと**：学校や街の人から頼まれ、探したり戦ったりして解決する。ごほうびつき。
- **街の寄り道**：昼の街を歩ける。店や、つりのような小さな遊び、道の秘密。
- 入れる時期：ガチャ（段階6）の前。仲間の手に入れ方が増えるので、ガチャはそれに合わせて作る。

## 6. 物語と登場人物

### 6.1 世界 ［決定］
- 表と裏がある社会。
- 楽しい学校生活と、家業の**義賊の怪盗**。
- 「本当の正義とは何か」を考えさせる。同時に、日常の楽しいわくわくした雰囲気を感じられる。

### 6.2 主人公（正反対のダブル主人公）［決定］
| | 女の子 | 男の子 |
|---|---|---|
| 学年 | 高校1年 | 高校1年 |
| 役割 | 実行役 | ハッキング・裏方 |
| 特徴 | 運動神経抜群、学力は低め、話し上手、甘いもの好き | 運動音痴、IQの高い天才、無口、機械とプログラミングが得意、コーヒー好き、料理上手 |

共通：幼なじみで信頼し合っている。それぞれ**1つ超人的な能力**を持つ。親が海外出張中で一緒に暮らしている。

戦いでの役割［案］：女の子はアタッカー。男の子は前に出ず、ハッキングで敵の弱点を暴く・味方を強める支援役。

### 6.3 仲間 ［案］
- クラスメイト、ライバル、街の情報屋など、**表と裏の顔を持つ人たち**。
- 物語で必ず加わる仲間は無料。それ以外はガチャで当たる。
- 4人の組み方は自由（主人公を外してもよい）。

### 6.4 見たい場面 ［決定］
- 学校行事（文化祭、運動会、テスト）
- ライバルとの戦い・共闘
- 主人公同士で助け合う
- 親の秘密が明かされる
- ラスボスを倒したあと、本当の裏ボスの意外な正体が分かる

## 7. 見た目と音

- **キャラ**：歩く・戦う・会話は **VRoid Studio で作った3Dキャラ**。ガチャで当たった時と物語の大事な場面だけ**1枚絵**。［決定］
  - VRoid のキャラはユーザーが作る。重さを抑えるため、書き出し時に面の数と絵の大きさを減らす（手順は Claude が書く）。［案］
  - **動き**：VRoid の書き出しには動きが入っていない。歩く・走る・攻撃などは全員で**共通の動き**を使い回す。まずは無料の VRMA（VRM用の動き）素材と、プログラムで作る動きで始め、足りなければ Mixamo（ユーザーがアカウントを作って落とす）を使う。キャラごとの差は、**必殺技の演出**（カメラの寄り・光・効果・1枚絵の差し込み）でつける。［案・作り手の判断］
  - 1枚絵はほかのAIで作る。同じキャラを同じ顔で描かせるのが難しいので、キャラごとに決まった指示文と見本の絵を用意する（Claude が書く）。［案］
  - 使うAIは **Gemini の画像（Nano Banana）**［決定 2026-11-20］。NovelAI と同じ指示文でためして、顔がそろいやすく、いまの Plus のまま横長で描けるので選んだ（docs/image-ai-trial.md）。はじめは未定で、1枚絵が要る段階になったら、Claude が候補を「同じ顔で描き続けられるか」「公開するゲームに使ってよい条件か」で比べておすすめを出し、ユーザーが選ぶ。VRoid の3Dキャラの画面写真を見本として読ませられるものを優先する。
- **場所・敵・効果**：外の素材（無料・使用条件の明確なもの）と、プログラムで作るものの組み合わせ。使った素材と使用条件は一覧に残す。［任せる］
- **音**：外の素材かAIで作った曲を使ってよい。使用条件は一覧に残す。［任せる］
- 文字：日本語のみから始める。［案］

## 8. 最初に作る範囲（第1章）［案］

- 場所：学校（拠点）、街、忍び込む建物1つ。
- キャラ：主人公2人＋物語で加わる仲間1人＋ガチャのキャラ3人＝**6人**。
- 敵：見回り・警備ロボなど数種、ボス1体。
- 物語：第1章の筋（文案は Claude が書いて、ユーザーが直す）。
- 行事のミニゲーム1つ。
- 育成（レベル・技・武器・装備・絆）とガチャ（キャラ・武器）。
- 続き（新章・新キャラ）はあとから足す。
- 長さのめあて：第1章は **2〜3時間**（怪盗パート3〜4回＋ボス）。［案・作り手の判断］
- 出す順番：全部そろうのを待たず、まず**中心の楽しさだけ遊べる版**（戦い＋レベル・装備＋ボス1体）を先に遊んでもらう。そのあと学校・ガチャ・物語を足す。［案・作り手の判断］
- 「第1章完成」＝ 上の中身が全部つながって、最初から第1章のボスを倒して終わりの場面まで通しで遊べること。

## 9. 作り方の決まり ［案］

- Three.js（新しい版）＋ three-vrm。TypeScript ＋ Vite。
- GitHub で管理。公開は GitHub Pages。
- 保存はブラウザの中（localStorage）。読んだ形は確かめて、おかしければ初期値に戻す。
- 遊ぶ機械：**Galaxy S26（Chrome）**。［決定］ ユーザーは iPhone を持っていないので、実機で確かめるのは Galaxy だけ。iPhone の人も遊べるよう、メモリは控えめに使う（目安は段階1で決める）。［案］ 戦い（キャラ4体＋敵）が滑らかに動き、落ちないこと。
- **最初に確かめること**：VRoid のキャラを4体＋敵で並べて、Galaxy S26 で重さとメモリを測る試作。重すぎれば、面の数を減らす・戦いは2体ずつ映す等で対策してから先へ進む。
