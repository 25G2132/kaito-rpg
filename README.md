# 怪盗RPG（仮）

スマホ横画面で遊ぶ、学校と怪盗の順番に戦うRPG。ブラウザ（Three.js ＋ VRoid の3Dキャラ）で作る。

- 設計：[docs/2026-11-18-design.md](docs/2026-11-18-design.md)
- 計画：[docs/2026-11-18-plan.md](docs/2026-11-18-plan.md)

## 動かし方

```bash
npm install
npm run dev
```

表示された `Network:` のアドレスを、同じWi-Fiのスマホで開く。左上に重さの表示が出る（公開版では `?perf` を付けると出る）。

- ふつうに開くと **先行版**（段階3）：拠点 → 戦う → ごほうび → 育てる。育てたデータはブラウザの中に保存される（拠点の「データを消す」で、はじめから）。
- `?novrm`：開発サーバーで見本の VRM を読まない。開発サーバーだけ、コンソールの `__kaito.skip('vault')` で戦いを一瞬で終わらせられる（確かめ用）。
- `?spike`：段階1の重さの試作。
- キャラの見た目：開発サーバーでは `public/models/sample-a.vrm` があれば自動で読む。公開ページでは「VRMを選ぶ」でスマホの中のファイルを選ぶ（再配布できないモデルは git に入れない）。無ければ仮の形で動く。
- `npm test`：自動テスト
- `npm run build`：公開用に組み立てる（`dist/`）

## 中身の置き場所

- `src/battle/`：戦いの計算（画面と切り離し、自動テストつき）。`auto.ts` は自動戦闘。
- `src/data/`：キャラ・敵・状態・属性・戦う相手のデータ。キャラを足すときはここだけ書けばよい。
- `src/progress/`：育成（レベル・突破・技・武器・装備・ごほうび・保存）。自動テストで釣り合いも確かめる。
- `src/ui/`：拠点と育成の画面。
- `src/battleView/`：戦いの画面（3D の舞台、表示、演出）。動きはプログラムで作っている（VRMA 素材はまだ使っていない）。
